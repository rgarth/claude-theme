# claude-theme

A sci-fi starship console theme for the Claude desktop and mobile apps.

Black background, flat pastel console frames, a star-field you're slowly flying through, and a side column with world clocks and a one-minute sensor dial. It can also show who's on call from PagerDuty.

## Install

```
claude plugin install bridge-theme --marketplace rgarth/claude-theme
```

Or in a Claude Code session: `/plugin install bridge-theme --marketplace rgarth/claude-theme`. In the desktop app: **+** next to the prompt, **Plugins**, **Add marketplace** `rgarth/claude-theme`, then add `bridge-theme`.

See [plugins/bridge-theme/README.md](plugins/bridge-theme/README.md) for the PagerDuty panel and options.
